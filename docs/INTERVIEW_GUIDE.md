# Interview guide: EDGE GLASS Social Intelligence Agent

Use this guide to explain the project accurately. The implementation was developed with AI assistance; be open about that and focus on understanding the system and its trade-offs.

## 60–90 second project explanation

> "I worked on an AI-assisted social intelligence system for EDGE GLASS. It has two workflows built with JavaScript on Google Apps Script. The scheduled workflow searches YouTube for configured smart-glass and architecture topics, collects public video metadata, sends records to Google Gemini for structured analysis, stores the research and history in Google Sheets, and generates an emailed daily report. The second workflow is an on-demand Google Sheets sidebar where a user enters a topic and gets Instagram Reel concepts generated by Gemini, informed by YouTube search results. I used AI tools to assist with the code, and my focus has been understanding the architecture, integrations, data flow, configuration, testing and limitations."

## Explain the technology choices

| Technology | What it does in this project |
|---|---|
| JavaScript / Apps Script V8 | Backend language and managed runtime for automation |
| Google Sheets | Data store and working interface |
| YouTube Data API v3 | Topic-based video discovery and public metadata |
| Google Gemini API | Structured research analysis and content ideation |
| HTML / CSS / client-side JavaScript | Sidebar interface |
| `google.script.run` | Connects the sidebar to server-side Apps Script functions |
| Time-driven triggers | Starts the daily workflow automatically |
| Apps Script Mail service | Sends the daily report |

## Main data flow

### Scheduled workflow

1. Trigger invokes the daily controller.
2. Controller starts topic-based YouTube research.
3. The backend collects public video information and avoids reprocessing known URLs.
4. Gemini analyses records in batches.
5. Results and history are saved to Sheets.
6. The report is generated and emailed.

### On-demand workflow

1. User opens the Content Studio sidebar.
2. User enters a topic.
3. Apps Script searches YouTube for supporting source material.
4. Gemini creates structured Reel concepts.
5. The concepts are saved to the Instagram Content Ideas tab.

## Questions you should be ready for

### 1. What language is the backend written in?

JavaScript running in the Google Apps Script V8 runtime. The sidebar is built with HTML, CSS and client-side JavaScript.

### 2. Where does the system run?

On Google's managed Apps Script infrastructure. It is not a personal-computer process or a separately managed Node.js server.

### 3. What is the role of Google Sheets?

It is both the user-facing interface and the persistent tabular data store for research, history, reports and generated ideas.

### 4. Why use YouTube Data API?

It provides a searchable source of public video metadata around the configured topics. Those records give the analysis workflow source material to work from.

### 5. What does Gemini contribute?

Gemini analyses collected metadata and produces structured research fields and creative content concepts. Its output is AI-generated and needs human review.

### 6. How does the system avoid duplicate research?

The workflow checks previously stored source URLs and avoids processing already recorded videos again.

### 7. What is historical intelligence tracking?

The workbook stores prior analyses and a change-status field. Observed values include BASELINE, NO CHANGE and CONTINUING.

### 8. How does the sidebar communicate with Apps Script?

The client-side interface uses `google.script.run` to call server-side Apps Script functions.

### 9. Does it monitor Instagram trends directly?

No. The Content Studio is Instagram-focused, but its supporting research comes from YouTube. It does not directly query the Instagram Reels feed.

### 10. Does it publish or schedule posts?

No. It creates text-based concepts and production guidance. It does not render finished videos or publish/schedule Instagram posts.

### 11. How are API keys protected?

They are configured as Apps Script Script Properties rather than hardcoded in source files. Never expose credentials in a public repository.

### 12. What are the main operational constraints?

API quotas, Apps Script execution limits, permissions, service availability and variability in AI responses.

### 13. What would you improve next?

Potential future work could include stronger validation of AI outputs, monitoring and failure alerts, clearer evaluation of recommendation quality, and carefully scoped competitor or audience research modules. These should be described as future work, not existing functionality.

### 14. How much of the code did you write?

Be transparent: "I used AI tools to help generate and refine the code. I took responsibility for understanding the system's requirements, structure, configuration, testing and behaviour, and I can explain how the components work together."
